## 横向规律(23 条视频的共性)

1. **题材=学生日常痛点,重复不可怕**:记账分摊 ×2(G02/G03)、求职面试 ×2(G06/G08)、学习类 ×3(G07/G15/G16,另 G18 文档问答)、校园生活 ×3(G10/G19/G22)、香港本地 ×3(G13/G17/G32)。同题撞车普遍,差异化靠一个硬功能点(OCR、汇率、弱项报告、RAG)。
2. **视频形态分两派,都可取**:实录派(模拟器/真机/浏览器实操,显扎实)与包装派(AI 生成片头、杂志风动效、样机幻灯片,观感上限高但无实机证据易被疑"是否真做了")。最优解是混合:模拟器实录为主,AI/动效片头点缀。
3. **AI 功能是标配,但要"绑定具体场景"**:收据 OCR(G03)、礼物推荐(G04)、多源+AI 精选(G07)、AI 安全专家(G11)、自然语言找房带兜底(G13)、课件 RAG 出题(G15)、AI 判填空(G16)、文档 RAG(G18)、AI 试穿(G20)、文字生成视频(G21)。亮点设计:**异步生成 + 等待页/通知**(不干等)、**"AI 判断中…"过程态**、**可解释理由页**("为什么推荐这个"做成 UI)。
4. **后端与账号体系是主流,但两种叙事都成立**:多数组有登录注册/多端同步;G22 反打"无账号、数据不出本机"隐私牌同样被接受——关键是文案自洽。
5. **零预算技术选型有成熟套路**:MapLibre 免地图 API 费(G17)、高德 URI scheme 外链代替 SDK(G19)、PWA 托管 Cloudflare Workers(G20)——对我们 Flutter + FastAPI 的省钱选型直接可用。
6. **演示设计"教室安全路径"**:G22 专门做 Classroom-safe demo 路线规避定位/网络风险;演示数据要真实且评审熟悉(G15 直接用本课课件出题、G13 用真实租房场景)——比任何解说都有说服力。
7. **制作反面教材**:用桌面播放器播放录屏交片(G06,控制条外露)、只有设计稿动效没有实机证据(G05/G07 的争议面)。
8. **技术栈大多无法从视频确证**:仅 G16 明确 Android Studio 模拟器、G04/G22 明确 iOS 模拟器;多数组只见样机截图/录屏,原生还是跨平台无法判断——说明评审也不靠"看得出什么框架"给分,演示效果和功能完整度才是硬道理。

## 逐组详录

## Group 01(时长 1:59)

- **App 名称/主题**:HKU Alumni Social App(HKU CONNECT)——面向港大校友的社交 App,主打校友联络、通讯与活动管理。
- **视频构成**:PPT 翻页为主线(蓝白 HKU 配色模板,结构:封面 → Core Features → Mobile Apps Demonstration),功能演示以手机录屏小窗嵌在 PPT 页面右侧播放。制作规整、模板统一,典型课堂 pre 风格。
- **界面与功能**:
  - 登录页:HKU alumni 品牌图 + HKU Email / Password 输入框 + Login 按钮(封面手机样机内展示)。
  - Core Features 页列出五大功能:HKU 邮箱安全登录(可编辑个人资料与 faculty 角色)、校友高级搜索(按姓名/邮箱/性别/角色/学院过滤)、一对一实时聊天(已读回执、未读数)、活动管理(浏览/报名,授权用户可创建 public/limited 活动)、收藏系统(收藏人与活动)。
  - 搜索结果页:紫色顶栏 + 校友卡片(角色/年龄/性别/学院/简介),底部导航栏五栏:Search / Favourite / Chat / Events / Profile。
  - 聊天页:深色对话背景,支持删除聊天记录(弹确认框,提示会同时删除双方消息)。
  - 创建活动页:表单含图片上传、标题、组织者、日期时间、地点、简介、容量、报名截止、Public/Limited 分类,提交后有"Event Created!"提示。
- **技术信号**:无 IDE 入镜,无法明确判断技术栈。演示录屏状态栏为 iOS 风格(时间/5G/电池 + 底部 home 横条),但删除确认对话框偏 Material 风格;有邮箱登录注册与实时聊天(已读回执),说明配了后端/实时数据库。综合:疑似跨端框架或 Android,iOS 风格状态栏也可能是模拟器皮肤,记为"无法判断"。
- **亮点/可借鉴**:功能闭环完整(登录→搜索→聊天→活动→收藏),适合作为"校园社交"选题的 scope 参考;演示形式(PPT 大标题 + 右侧录屏小窗逐功能过)很讨巧,录屏不用全屏也能看清 UI,我们组做演示视频可直接套用该版式。

## Group 02(时长 3:00)

- **App 名称/主题**:SplitLeaf——旅行/活动的多人费用分摊(AA 记账)App。
- **视频构成**:Zoom 会议录屏(右侧可见参会者面板):前半段屏幕共享 PowerPoint 放映(窗口标题含 mobile app ppt.pptx,PPT 做成网站导航样式:Home/About/Features/Demo),后半段切到 Safari 浏览器现场操作演示。典型线上 pre 录屏,制作朴实。
- **界面与功能**:
  - PPT 封面:SplitLeaf 品牌(绿叶 logo),定位"group expense splitting app for trips and events"。
  - About 页:支持 150+ 币种、按历史汇率自动换算、计算最简 "who owes who" 结算路径。
  - App 首页(浏览器移动视口):空状态 "No events yet — create your first one!",右下角绿色 + FAB。
  - Add Expense 表单:费用名、日期、金额、支付币种下拉(带国旗,如 JPY)、实时汇率换算提示(1 JPY = 0.04832 HKD,JPY 5,000 ≈ HKD 241.63)、Paid by 成员下拉、Split between 成员多选 chips、右上角有相机图标(疑似收据拍照)。
  - 行程详情页(如 Japan trip):总支出卡片(HKD 474.70 / 3 expenses)、Expenses/Balances 双 tab、成员余额正负着色(gets back 绿 / owes 红)、Suggested settlements 给出最优转账路径 + Settle 按钮。
- **技术信号**:明确是 **macOS Safari 里跑 localhost 的 Web App**(地址栏可见 localhost,移动宽度视口),不是原生模拟器;具体框架无法判断(Flutter Web / React / Vue 均有可能)。汇率换算说明接了汇率数据(API 或内置历史汇率)。未见登录注册流程。
- **亮点/可借鉴**:多币种 + 历史汇率换算是差异化卖点,接外部 API 的思路可搬;"Suggested settlements" 最简转账路径是记账类 App 的加分算法。另外注意:课程接受 localhost web 形态做 demo,但视觉正式度不如模拟器录屏,我们 Flutter 项目走模拟器/真机录屏会更显正式。

## Group 03(时长 2:49)

- **App 名称/主题**:SplitShare——朋友间账单记录与 AA 分摊 App,带收据扫描。
- **视频构成**:英文配音讲解 + 底部大字幕(疑似 AI 字幕);画面大量采用**双屏并排**(左功能页录屏、右首页或真机画面),中间夹了一段**真机实拍**(手持 iPhone 扫另一台设备的 QR 码)。制作质量在目前已看组里最高,剪辑有设计感。
- **界面与功能**:
  - 登录页:Sign in with Apple 黑色按钮 + 邮箱/密码登录 + Sign up 入口。
  - 首页:问候语 + 头像,紫色大卡片 "Split a Bill(扫收据分摊)",功能入口:Plan a Trip / Join a Trip(输 5 位房间码)/ Send Money(App 内转账)/ Create Blank Receipt(手动记账);底部 tab:Home/Friends/History/Profile。
  - History 页:搜索 + All/Open/Settled/This month 过滤 chips,按月分组的账单卡片,金额正负着色(Owed to you 绿 / You owe 红)。
  - Friend QR:My code(含个人 ID 的二维码 + 分享好友码)/ Scan code(相机取景扫码)双 tab。
  - Review Split(收据扫描后确认页):收据缩略图可点开原图,SPLIT MODE 支持 Equal split / By item 两种,逐项可编辑金额(Done/Cancel/Delete),自动算 tip + tax。
  - Trip 详情页:房间码 + Invite、TRIP TOTAL、成员 BALANCES 正负、SUGGESTED PAYMENTS 最优转账路径、Mark as paid、**PayMe 深链支付**(payme.hsbc)、Mark everything settled。
- **技术信号**:明显 iOS 向(状态栏 9:41 模拟器特征 + Sign in with Apple + iPhone 灵动岛真机),疑似 iOS 模拟器录屏 + 真机实拍混合;具体原生 Swift 还是跨端无法判断。功能侧确认:Apple 登录(有后端鉴权)、**收据 OCR 扫描**(AI/ML 接入)、相机扫码、房间码组队、PayMe 深链。
- **亮点/可借鉴**:收据 OCR + By item 逐项分摊是硬差异化功能,我们组可考虑把"拍照识别"类 AI 能力接进 FastAPI 后端;双屏并排的剪辑让 2 分半视频信息密度翻倍,值得学;房间码 + QR 双通道加好友/组队机制可直接搬到任何多人协作选题。

## Group 05(时长 1:47)

- **App 名称/主题**:PlayStage——亲子陪伴指导 App:教家长陪孩子玩时"说什么、观察什么、为什么有用",slogan「玩甚麽·說甚麽·為甚麽」。
- **视频构成**:开头是 **AI 生成的情景短片**(温馨客厅、父子玩耍,广告片质感)→ 品牌标题卡(马卡龙色 3D 形状 + 衬线字体)→ 特性页逐条展示(左文案 + 右手机框内界面)。无真人出镜、无 PPT 翻页;手机内界面过于干净、全程无操作动态,**更像设计稿/Figma 原型动画而非真实录屏**。观感是已看组里最精致的。
- **界面与功能**:
  - Play 页(活动指导):What to Say 话术气泡(斜体示例句,带 Simple questions/Encouragement/Emotion talk/Turn-taking 标签)、What to Observe 观察要点、Why this activity helps 发展意义,可收藏。
  - Family 页:账户信息、家庭组(含创建日期)、Summary of this week 周报(周区间切换、孩子 chips 切换)、"Did we show up?" 参与统计(play moments / 天数 / 分钟数)、一周日历勾选、"How baby felt" 情绪记录(如 Upset·1、warm moments 计数)。
  - 底部 tab:Home / Play / Calendar / Learn / Family。
- **技术信号**:**无法判断技术栈**——未见模拟器/真机录屏,界面以手机框 mockup 形式呈现,无法确认是否存在可运行 App;无 IDE、无状态栏动态。视频本身确认使用了 AI 视频生成(片头情景)。
- **亮点/可借鉴**:演示视频的"广告片打法"上限很高——AI 情景片头 + 品牌页 + 左文右机特性页,我们组若追求观感可复用此结构(用 AI 生成使用场景短片当片头);"说什么/观察什么/为什么"三段式内容设计适合一切指导类选题。注意风险:全 mockup 无实机操作,若课程看重真实实现,这种打法可能反噬,建议我们仍以真机/模拟器录屏为主、AI 片头为辅。

## Group 06(时长 2:08)

- **App 名称/主题**:InterviewMate——求职面试复盘记录 App:记录每场面试的题目与自己的回答并自评,自动生成复盘报告与练习推荐。
- **视频构成**:英文配音 + 大字号字幕;画面是 **Windows 桌面录屏**——用系统"媒体播放器"(中文 Windows)播放一段手机操作录屏,左上角叠 "Group 6 InterviewMate Demo" 标题,右下角有系统时间戳;末段播放器控制条外露,制作较粗糙(播放器窗口直接入镜)。
- **界面与功能**:
  - Interviews 列表页:搜索(公司/职位)+ 面试卡片(公司、职位、日期、轮次如 First Round、题数、Avg 分、状态 badge:Pending/Failed),右下 + FAB;底部 tab:Interviews / Question Bank / Profile。
  - 面试记录编辑页:轮次 chips(First/Second/Third)、结果(Passed/Pending/Failed)、Overall Notes、逐题录入(Category:Algorithms/System Design/Behavioral + 题目 + My Answer + Self Rating 1-5),可 Add Question。
  - Review Report 页(核心):总分大数字 + 进度条 + 一句话总评;Category Scores 分类条形图(含 Not Seen 态);弱项识别提示("Algorithms, System Design are tied as weak areas")+ 针对性建议;Recommended Practice 按弱项推题,每题带难度(Difficulty 2)和完整参考答案(含 ML/JVM/Transformer 公式级解析)。
  - Profile 页:Overview 统计(Total/Passed/Pending/Failed)、Skill Averages 四维雷达图 + 数值条、Recent 3 Interviews。
