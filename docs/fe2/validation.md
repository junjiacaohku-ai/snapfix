## 真实管线与安全

- `server/pipeline.py` 已实现质量门、Gemini 视觉、归一化、BM25、安全门、结构化生成和引用校验。
- 替代 provider 测试覆盖高危短路、低置信度、空召回、伪造引用、危险生成、型号缺失和生成失败回退。
- 真实语料测试确认 Bosch E24 候选手册第 35 页进入检索结果。
- `source_mode` 区分 mock、retrieval、gemini，并已加入 SQLite 旧库自动迁移；回退不会冒充真实识别。
- E24 预览在型号未核实前只建议专业处理；步骤反馈演示使用路由器外部操作。
- 正式诊断、案例和续诊统一使用 `safety_gate.py`，不保留 FE-2 私有高危规则。

## 产品 UI 与隐私

- 产品 UI 在能力可用时统一调用 v1 图片/手动诊断并导入 UI 记录；无真实能力时明确显示未支持或使用显式预览。
- 普通照片验证后只保留文件名，续诊使用 `photo_ref`，数据库不保存原图。
- 主题色与 landing 统一为 #0B1020 / #F5A623，默认 API 端口统一为 8000。
- 路由器演示已补齐 TP-Link / TL-WR940N 字段；iOS 真实流程曾先发现该缺失，修复后完整套件通过。
