## 已确认的本轮设计范围

- 沿用 AI Studio 的布局、深色卡片、琥珀色主按钮、单列大图案例及悬浮底栏；不擅自重做视觉。
- 只有一个“预览使用流程”入口。预设照片、诊断与步骤由该入口进入；入口内说明数据性质，普通页面不重复增加演示标签。
- 普通拍照/选图读取实际照片；没有可用的真实诊断能力时显示“还在学习该维修技能中！”。断网、超时或服务不可用单独处理。
- 演示预填的 15m、10–15 分钟、毛巾/软毛刷可保留。实际诊断缺少这些数据时显示待核实/待评估/以适用手册为准。
- 筛选维度切换重置旧标签，跨对象/语言保留本页编辑，草稿由后端保存。
- 以后涉及文案、UI 和交互方式的变更先提交用户检查，得到同意后才执行。本轮是按2026-11-05之前已确认内容实现。

## 交付边界

本轮不会把队友的数据、主题骨架或模型服务记成本人的原创成果。真实故障识别未接通，正式入口只上传/记录输入，绝不借用演示结果冒充识别。接口测试、桌面浏览器与 Flutter Web 验证不能代替 Android/iOS 真机验收；全组评审、真实 provider 验收、GitHub 合并和个人 Peer Review 需分别留证。

## 原分工之外的整合

为支持用户设计，新增 /api/fe2 路由提供案例、记录状态、续诊、六种对象/语言草稿等契约；原 /api/sessions、feedback、report、检索及数据导入接口保留。新增字段存于同一 SQLite 文件内的独立 fe2_sessions 表，避免直接修改队友原表结构。合并时需要 FE-1、BE-1/BE-2 对齐契约；这不是未经审阅的 main 覆盖包。
